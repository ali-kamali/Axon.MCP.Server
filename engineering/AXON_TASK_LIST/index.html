    How to Use (for humans + coding agents)

    1. Single source of truth: Use this file for active/planned/blocked Axon tasks.
    2. State transitions: Move tasks between state sections only (don’t duplicate).
    3. Ordering rules:
    4. INCOMPLETE, IN_PROGRESS, and BLOCKED must stay sorted by priority (P0 highest → P3 lowest).
    5. If same priority, sort by task ID.
    6. Done timestamps: When moving a task to DONE, add completed_at=<ISO-8601 UTC>.
    7. Priority discipline:
    8. P0 = urgent/release or correctness risk
    9. P1 = important near-term hardening
    10. P2 = medium-value improvements
    11. P3 = low urgency / cleanup
    12. Task format (required fields):
    13. id, priority, owner, summary, next_step
    14. Optional: blocked_reason, depends_on, links
